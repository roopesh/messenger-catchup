Refreshing

  • To pull new messages, ask Claude in chat to refresh my catch-up. Claude reads your open Messenger tab in your own Chrome, scrolls back only to the last message already stored, appends the new ones here and rebuilds the summary. This page can't reach your Messenger tab itself.
  • Your computer has to be online. Every refresh, scheduled or not, drives the Messenger tab in your Chrome: the computer must be on and awake, the screen unlocked, Chrome open with the Claude in Chrome extension connected, Facebook signed in, and the Messenger tab open. If it isn't, that run is skipped and the next one catches up.
  • Mark caught up (Summary tab) sets the "Last Mark caught up" marker to the newest stored message and switches to it. At the top of the page you choose where the catch-up starts: your last Mark caught up, your last message in the chat, or a date range. The summary, questions, deals and topics then cover only what comes after that point; nothing older is carried forward.
  • Older messages are kept as history. See them under Messages with "Show older messages", or include them in Ask Claude with its checkbox.
  • Reply in Messenger ↗ (on every card, open question and message) opens Messenger at that exact message with the Reply box ready, once the helper below is set up. Without it, the link just opens the chat. Older messages take 10–20 seconds while it scrolls back.
  • Reply here (works from your phone): type your reply on this page. It waits under “Your replies” at the top of Summary. On its next run Claude shows you each queued reply in chat and posts it only after you confirm there. Cancel any time before then.

Jump to a message: set up (pick one)

Makes every “Reply in Messenger ↗” link land on the exact message with Reply open.

1. Automatic (recommended, optional): Messenger Catch-up Helper userscript (Tampermonkey or Violentmonkey). Every link jumps by itself, and Claude's refreshes run faster and use far less of your usage. Without it Claude injects the same code into your Messenger tab on each run.

  • Install Tampermonkey (recommended) or Violentmonkey in Chrome. In current Chrome, allow user scripts: chrome://extensions › the extension › Details › Allow User Scripts (older Chrome: turn on Developer mode at the top right instead).
  • Open Install the userscript. The extension shows its install page: press Install. It updates itself from then on.
  • Reload your Messenger tab. Tell Claude “installed” and it checks the helper is running (it marks the page with data-mc-helper).

2. No install: bookmarklet. Two clicks: the link opens Messenger, then click the Jump bookmark.

  • Drag this to your bookmarks bar: Jump (or copy the code below, make a new bookmark and paste it as the URL).

3. Nothing to set up: ask Claude. Say “reply 3232” (or “open #3232”) in chat. Claude opens it in your Messenger tab with Reply ready. It takes about 30 seconds and needs your computer awake.

Import capture

Claude uses this during a refresh; you don't need to.

During a refresh Claude copies the messages it read in Messenger and pastes them here, so it doesn't have to retype them. The page checks the checksum, the numbering and the overlap with what's already stored before it saves anything, then reads the saved messages back.
