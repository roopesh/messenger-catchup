# Working in this repo

The instructions for every coding agent working here are in [CLAUDE.md](CLAUDE.md). Read it first and follow it; it isn't specific to Claude. It covers the branch → PR → version → merge rule, versioning, the public-repo rules, and how the plugin's four skills (`setup`, `refresh`, `replies`, `reply-check`) are laid out. Then read [docs/STATUS.md](docs/STATUS.md) for the current state and how to test, and, if you work in a git worktree, [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) › Working in a git worktree.
